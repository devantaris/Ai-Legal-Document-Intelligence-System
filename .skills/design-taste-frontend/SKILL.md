# tasteskill: Anti-Slop Frontend Skill

> Serious, minimal, light-mode, high-density, professional UI.
> No AI-purple gradients, no dark-mode neon tropes, no Gen Z gadgetry.
> Every layout is intentional, clean, and restrained.

## Core Rules for LegalIQ:
1. **Light Mode Only**: Warm neutral paper base (`#f8f8f7` / `#fafafa`), clean pure white surfaces (`#ffffff`), subtle hairline borders (`#e5e5e5` / `border-neutral-200`), dark crisp text (`#111111` / `#555555`).
2. **Minimalism**: Remove all decorative noise, confetti, emoji overload, sound gadgets, and flashy gimmicks.
3. **Typography**: Clean, high-legibility sans-serif with disciplined hierarchy. Maximum 2-line headlines, max 20-word subtexts.
4. **Single Restrained Accent**: High-contrast, mature accent (deep indigo/slate `#1e293b` or `#312e81`).
5. **Architectural 3D**: Subtle, refined light-mode WebGL geometry (graphite wireframe on warm paper background), not glowing neon cyber meshes.
